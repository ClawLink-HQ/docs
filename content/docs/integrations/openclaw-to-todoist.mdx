## At a glance

- Useful for task capture, follow-up reminders, and turning notes into action items.
- Good fit when you want OpenClaw to move from suggestions into actual task creation.
- If projects do not appear, confirm you connected the right Todoist account.

## Example prompts

- "Create a Todoist task from this meeting note"
- "List my overdue Todoist tasks"
- "Add a follow-up reminder for Friday"
- "Turn these action items into Todoist tasks"

## If it does not work

- Start a fresh agent session after setup so the ClawLink tools load
- Make sure you approved the browser pairing flow
- Make sure Todoist is connected in the ClawLink dashboard
- Confirm the connected Todoist account and project access match what you expect
