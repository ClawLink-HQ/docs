# Connect OpenClaw to Notion

![OpenClaw and Notion connection concept](/images/articles/clawlink-notion-hero.png)

Use this if you want OpenClaw to search your Notion pages, create pages, and help with your workspace.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Notion">
    Go to the ClawLink dashboard and connect **Notion**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Notion.
  </Step>
</Steps>

## Example prompts

- "Search Notion for onboarding notes"
- "Find the page about our roadmap"
- "Create a new Notion page called Feature Ideas"
- "Summarize my Notion notes about customer interviews"

## If it does not work

- Start a **new OpenClaw chat** after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Notion is connected in the ClawLink dashboard
