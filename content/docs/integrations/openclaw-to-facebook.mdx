## At a glance

- Useful for Page posting, social workflow automation, and Meta-connected app flows.
- Some Facebook capabilities depend on the exact Meta app permissions and account type you connect.
- If your goal is Instagram automation, you may also need the related Meta/Facebook Page wiring in place.

## Example prompts

- "Draft a Facebook Page post for our new feature launch"
- "Summarize our recent Facebook Page activity"
- "Help me prepare a Facebook post from this product update"
- "Turn this launch note into a short Facebook announcement"

## If it does not work

- Start a fresh agent session after setup so the ClawLink tools load
- Make sure you approved the browser pairing flow
- Make sure Facebook is connected in the ClawLink dashboard
- Check that the connected Meta account has the right Page/business permissions
