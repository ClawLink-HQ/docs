# Connect OpenClaw to Salesforce

Use this if you want OpenClaw to help with Salesforce records, opportunities, and CRM workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Salesforce">
    Go to the ClawLink dashboard and connect **Salesforce**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Salesforce.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Good for account lookups, opportunity updates, and CRM housekeeping.
- Salesforce often fails because the wrong org or permissions were connected.
- If record access looks incomplete, the issue is usually on the Salesforce side, not OpenClaw.

## Example prompts

- "Find the Salesforce account for Acme"
- "Update this opportunity stage in Salesforce"
- "Summarize open opportunities closing this month"
- "Create a Salesforce lead from these notes"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Salesforce is connected in the ClawLink dashboard
- Confirm you connected the right Salesforce org and granted the scopes you need
