## At a glance

- Good for file retrieval, upload workflows, and document search across your Drive.
- Very useful when OpenClaw needs to find or organize files without manual clicking.
- If files are missing, the connected Google account probably does not have access to that Drive content.

## Example prompts

- "Find the latest proposal in Google Drive"
- "Search Drive for onboarding docs"
- "Summarize the newest files in this folder"
- "Help me find the spreadsheet I used for last month's report"

## If it does not work

- Start a fresh agent session after setup so the ClawLink tools load
- Make sure you approved the browser pairing flow
- Make sure Google Drive is connected in the ClawLink dashboard
- Confirm the connected Google account can access the files/folders you want
