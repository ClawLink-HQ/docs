# Connect OpenClaw to Google Drive

Use this if you want OpenClaw to help with Google Drive files, search, and document workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Google Drive">
    Go to the ClawLink dashboard and connect **Google Drive**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Google Drive.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Good for file retrieval, upload workflows, and document search across your Drive.
- Very useful when OpenClaw needs to find or organize files without manual clicking.
- If files are missing, the connected Google account probably does not have access to that Drive content.

## Example prompts

- "Find the latest proposal in Google Drive"
- "Search Drive for onboarding docs"
- "Summarize the newest files in this folder"
- "Help me find the spreadsheet I used for last month's report"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Google Drive is connected in the ClawLink dashboard
- Confirm the connected Google account can access the files/folders you want
