# Connect OpenClaw to Apollo

Use this if you want OpenClaw to research leads, look up companies, and help with outbound sales workflows in Apollo.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Apollo">
    Go to the ClawLink dashboard and connect **Apollo**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Apollo.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Good for lead research, prospect lookups, and outbound workflow prep.
- Best when you want OpenClaw to work from real company/contact data instead of guessing.
- If tools seem missing, start a fresh OpenClaw chat after pairing and connecting Apollo.

## Example prompts

- "Find Apollo contacts for product managers at fintech startups in Singapore"
- "Look up the company details for this domain in Apollo"
- "Find likely decision-makers for this account and summarize them"
- "Create a lead research summary from Apollo results"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Apollo is connected in the ClawLink dashboard
- Confirm the Apollo account you connected has access to the data you expect
