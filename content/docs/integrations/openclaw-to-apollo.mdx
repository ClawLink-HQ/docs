## At a glance

- Good for lead research, prospect lookups, and outbound workflow prep.
- Best when you want OpenClaw to work from real company/contact data instead of guessing.
- If tools seem missing, start a fresh OpenClaw chat after pairing and connecting Apollo.

## Example prompts

- "Find Apollo contacts for product managers at fintech startups in Singapore"
- "Look up the company details for this domain in Apollo"
- "Find likely decision-makers for this account and summarize them"
- "Create a lead research summary from Apollo results"

## If it does not work

- Start a fresh agent session after setup so the ClawLink tools load
- Make sure you approved the browser pairing flow
- Make sure Apollo is connected in the ClawLink dashboard
- Confirm the Apollo account you connected has access to the data you expect
