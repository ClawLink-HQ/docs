Connect your Notion workspace to ClawLink, and your agent can search pages, query databases, create pages and add content. Notion connects with one hosted sign-in. You do not create a Notion integration or copy a token.

## What your agent can do

<CardGroup cols={2}>
  <Card title="Read pages" icon="file-text">
    Find any page you shared and read it as Markdown.
  </Card>
  <Card title="Query databases" icon="table">
    Search and filter database rows, and add or update rows.
  </Card>
  <Card title="Create pages" icon="file-plus">
    Add new pages under a parent page or in a database.
  </Card>
  <Card title="Write content" icon="pencil">

  </Card>
</CardGroup>

## Set up

<SetupTabs app="Notion" />

When you connect Notion, Notion asks which pages ClawLink can access. Pick the pages and databases your agent needs. You can change this list later in Notion, under **Settings > Connections**.

## Common actions

| Action | What it does |
|---|---|
| `search_notion_page` | Find pages and databases by title |
| `get_page_markdown` | Read a page as Markdown |
| `query_database` | List the rows of a database, with filters and sorting |
| `create_notion_page` | Create a page under a parent page |
| `insert_row_database` | Add a row to a database |
| `append_text_blocks` | Add paragraphs, headings and lists to a page |
| `update_page` | Change a page's title or properties |
| `create_comment` | Comment on a page |

Ask your agent "Using ClawLink, list the Notion actions" to see all 50+ of them.

## Troubleshooting

### A page is not found

ClawLink can see only the pages you shared when you connected. In Notion, open the page, click **•••** > **Connections**, and add ClawLink. Or reconnect Notion in the dashboard and pick the page.

### Permission denied

The Notion account you connected cannot edit that page. Ask the page owner for edit access, or connect a different account.

### The connection shows "Needs reconnect"

Open **Dashboard > Connections**, open Notion and click **Reconnect**.
