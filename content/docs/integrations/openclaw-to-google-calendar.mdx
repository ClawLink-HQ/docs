# Connect OpenClaw to Google Calendar

Use this if you want OpenClaw to check your schedule, summarize upcoming events, and help with calendar workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Google Calendar">
    Go to the ClawLink dashboard and connect **Google Calendar**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Google Calendar.
  </Step>
</Steps>

## ![Lightbulb icon](/images/icons/lightbulb.svg) At a glance

- Best for schedule lookups, agenda summaries, and event-based reminders.
- If the calendar was connected after plugin install, start a **new OpenClaw chat** before testing.
- If results look empty, make sure the right Google account is connected in ClawLink.

## Example prompts

- "What is on my calendar today?"
- "Summarize my meetings for tomorrow"
- "Do I have any free time this afternoon?"
- "Find the next meeting with Acme"

## If it does not work

- Start a **new OpenClaw chat** after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Google Calendar is connected in the ClawLink dashboard
- Check that you connected the correct Google account
