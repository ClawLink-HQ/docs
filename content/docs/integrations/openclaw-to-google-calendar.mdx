<SetupTabs app="Google Calendar" />

## At a glance

- Best for schedule lookups, agenda summaries, and event-based reminders.
- If the calendar was connected after plugin install, start a **new OpenClaw chat** before testing.
- If results look empty, make sure the right Google account is connected in ClawLink.

## Example prompts

- "What is on my calendar today?"
- "Summarize my meetings for tomorrow"
- "Do I have any free time this afternoon?"
- "Find the next meeting with Acme"

## If it does not work

- Start a **new OpenClaw chat** after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Google Calendar is connected in the ClawLink dashboard
- Check that you connected the correct Google account
