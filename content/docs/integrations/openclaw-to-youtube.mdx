# Connect OpenClaw to YouTube

Use this if you want OpenClaw to help with YouTube uploads, metadata, and channel workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect YouTube">
    Go to the ClawLink dashboard and connect **YouTube**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use YouTube.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Good for video publishing workflows, metadata prep, and channel operations.
- YouTube integrations usually depend on the connected Google account owning or managing the correct channel.
- If uploads are missing, verify channel access first.

## Example prompts

- "Draft a YouTube title and description for this tutorial"
- "Prepare upload metadata for this new video"
- "Summarize recent YouTube channel performance"
- "Turn this release note into a YouTube description"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure YouTube is connected in the ClawLink dashboard
- Confirm the connected Google account manages the right YouTube channel
