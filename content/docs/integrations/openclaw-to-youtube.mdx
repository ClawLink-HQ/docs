## At a glance

- Good for video publishing workflows, metadata prep, and channel operations.
- YouTube integrations usually depend on the connected Google account owning or managing the correct channel.
- If uploads are missing, verify channel access first.

## Example prompts

- "Draft a YouTube title and description for this tutorial"
- "Prepare upload metadata for this new video"
- "Summarize recent YouTube channel performance"
- "Turn this release note into a YouTube description"

## If it does not work

- Start a fresh agent session after setup so the ClawLink tools load
- Make sure you approved the browser pairing flow
- Make sure YouTube is connected in the ClawLink dashboard
- Confirm the connected Google account manages the right YouTube channel
