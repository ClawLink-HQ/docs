# Connect OpenClaw to Slack

![OpenClaw and Slack connection concept](/images/articles/clawlink-slack-hero.png)

Use this if you want OpenClaw to send messages, post updates, and help with Slack workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Slack">
    Go to the ClawLink dashboard and connect **Slack**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Slack.
  </Step>
</Steps>

## Example prompts

- "Send a message to #general with today's update"
- "Post this summary to the product channel"
- "Find the latest Slack discussion about onboarding"
- "Draft a Slack message from these notes"

## If it does not work

- Start a **new OpenClaw chat** after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Slack is connected in the ClawLink dashboard
