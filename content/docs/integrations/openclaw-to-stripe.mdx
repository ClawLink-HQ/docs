# Connect OpenClaw to Stripe

Use this if you want OpenClaw to help with Stripe customers, invoices, subscriptions, and billing workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Stripe">
    Go to the ClawLink dashboard and connect **Stripe**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Stripe.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Useful for payment lookups, invoice workflows, and billing support tasks.
- Stripe access should be scoped carefully because billing data is sensitive.
- If actions fail, double-check restricted key permissions or account access.

## Example prompts

- "Find failed Stripe payments from the last 7 days"
- "Look up the latest invoice for this customer"
- "Summarize active subscriptions in Stripe"
- "Create a billing support summary from recent payment events"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Stripe is connected in the ClawLink dashboard
- Confirm the connected Stripe credentials have access to the data and actions you expect
