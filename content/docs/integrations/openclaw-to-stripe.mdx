## At a glance

- Useful for payment lookups, invoice workflows, and billing support tasks.
- Stripe access should be scoped carefully because billing data is sensitive.
- If actions fail, double-check restricted key permissions or account access.

## Example prompts

- "Find failed Stripe payments from the last 7 days"
- "Look up the latest invoice for this customer"
- "Summarize active subscriptions in Stripe"
- "Create a billing support summary from recent payment events"

## If it does not work

- Start a fresh agent session after setup so the ClawLink tools load
- Make sure you approved the browser pairing flow
- Make sure Stripe is connected in the ClawLink dashboard
- Confirm the connected Stripe credentials have access to the data and actions you expect
