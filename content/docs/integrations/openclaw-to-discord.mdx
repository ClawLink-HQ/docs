# Connect OpenClaw to Discord

Use this if you want OpenClaw to help with Discord messages, server workflows, and lightweight community operations.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Discord">
    Go to the ClawLink dashboard and connect **Discord**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Discord.
  </Step>
</Steps>

## ![Monitor icon](/images/icons/monitor-cog.svg) At a glance

- Useful for posting updates, checking recent activity, and helping with Discord-based workflows.
- If Discord actions do not show up right away, start a **fresh chat** after the connection is added.
- Make sure the connected Discord account/server permissions match what you expect.

## Example prompts

- "Post this update to our Discord channel"
- "Summarize the latest Discord discussion about onboarding"
- "Draft a Discord announcement from these notes"
- "Find the recent Discord messages about pricing"

## If it does not work

- Start a **new OpenClaw chat** after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Discord is connected in the ClawLink dashboard
- Check that the connected Discord account has the needed permissions
