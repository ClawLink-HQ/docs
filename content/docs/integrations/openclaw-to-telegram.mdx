# Connect OpenClaw to Telegram

Use this if you want OpenClaw to help with Telegram messages, alerts, and bot-driven workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Telegram">
    Go to the ClawLink dashboard and connect **Telegram**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Telegram.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Useful for alerts, simple messaging workflows, and bot-based communication.
- Telegram setups usually fail because the bot is not in the right chat or does not have the needed permissions.
- If you expect group actions, confirm the bot was actually added there.

## Example prompts

- "Send a Telegram update with today's sales summary"
- "Draft a Telegram message for our user group"
- "Post this alert to my Telegram channel"
- "Help me turn this changelog into a short Telegram update"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Telegram is connected in the ClawLink dashboard
- Check that the connected bot is in the target chat/channel and has permission to post
