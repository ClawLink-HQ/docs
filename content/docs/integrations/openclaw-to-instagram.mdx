# Connect OpenClaw to Instagram

Use this if you want OpenClaw to help with Instagram publishing, captions, and business-account workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Instagram">
    Go to the ClawLink dashboard and connect **Instagram**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Instagram.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Best for caption drafting, content workflow help, and supported Instagram business actions.
- Instagram setups often fail because the account is personal instead of Business/Creator or is not linked through Meta correctly.
- If you also need Page-level permissions, the Facebook side of the Meta setup matters too.

## Example prompts

- "Draft an Instagram caption for this product screenshot"
- "Prepare an Instagram post announcing our launch"
- "Turn this changelog into an Instagram carousel caption"
- "Help me plan a week of Instagram posts for ClawLink"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Instagram is connected in the ClawLink dashboard
- Check that the Instagram account is a Business or Creator account linked to the right Meta assets
