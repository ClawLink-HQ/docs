# Connect OpenClaw to Twitter / X

Use this if you want OpenClaw to help with X posts, threads, and lightweight social publishing workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Twitter / X">
    Go to the ClawLink dashboard and connect **Twitter / X**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Twitter / X.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Useful for drafting short posts, threads, and announcement workflows.
- X integrations often depend on developer/app permissions and account access level.
- If posting fails, the issue is usually on the connected X app/account side.

## Example prompts

- "Draft a short X post announcing our launch"
- "Turn this changelog into a thread"
- "Write three X post options for this feature update"
- "Summarize this note into a tweet-sized post"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Twitter / X is connected in the ClawLink dashboard
- Check that the connected X developer app/account has the permissions needed for the actions you want
