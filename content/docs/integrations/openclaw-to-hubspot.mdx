## At a glance

- Good for CRM lookups, sales summaries, and moving faster on contact/deal workflows.
- HubSpot guides tend to fail because the wrong workspace/account got connected.
- If the tool seems missing, start a **fresh chat** after pairing and connecting.

## Example prompts

- "Find the HubSpot contact for Acme"
- "Summarize our open deals in HubSpot"
- "Create a new HubSpot contact from these notes"
- "Show me the latest activity for this company"

## If it does not work

- Start a **new OpenClaw chat** after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure HubSpot is connected in the ClawLink dashboard
- Confirm you connected the correct HubSpot workspace/account
