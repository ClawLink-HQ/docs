# Connect OpenClaw to HubSpot

Use this if you want OpenClaw to help with contacts, companies, deals, and CRM workflows in HubSpot.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect HubSpot">
    Go to the ClawLink dashboard and connect **HubSpot**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use HubSpot.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Good for CRM lookups, sales summaries, and moving faster on contact/deal workflows.
- HubSpot guides tend to fail because the wrong workspace/account got connected.
- If the tool seems missing, start a **fresh chat** after pairing and connecting.

## Example prompts

- "Find the HubSpot contact for Acme"
- "Summarize our open deals in HubSpot"
- "Create a new HubSpot contact from these notes"
- "Show me the latest activity for this company"

## If it does not work

- Start a **new OpenClaw chat** after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure HubSpot is connected in the ClawLink dashboard
- Confirm you connected the correct HubSpot workspace/account
