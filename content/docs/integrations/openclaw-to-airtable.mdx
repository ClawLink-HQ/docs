# Connect OpenClaw to Airtable

![OpenClaw and Airtable connection concept](/images/articles/clawlink-airtable-hero.png)

Use this if you want OpenClaw to read records, create entries, and help with Airtable workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Airtable">
    Go to the ClawLink dashboard and connect **Airtable**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Airtable.
  </Step>
</Steps>

## Example prompts

- "Find the Airtable record for Acme"
- "Create a new Airtable record for this lead"
- "Summarize the latest entries in my content table"
- "Turn these notes into an Airtable record"

## If it does not work

- Start a **new OpenClaw chat** after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Airtable is connected in the ClawLink dashboard
