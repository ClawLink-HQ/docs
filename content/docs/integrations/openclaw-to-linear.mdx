# Connect OpenClaw to Linear

Use this if you want OpenClaw to help with Linear issues, backlogs, and product-engineering workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Linear">
    Go to the ClawLink dashboard and connect **Linear**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Linear.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Good for triage, sprint support, backlog cleanup, and issue creation.
- Linear is especially useful when you want OpenClaw to turn raw notes into action items.
- If teams/projects do not appear correctly, the connected account likely lacks workspace access.

## Example prompts

- "Create a Linear issue from this bug report"
- "Summarize urgent issues in the current cycle"
- "Find all Linear issues assigned to me"
- "Turn this meeting note into a Linear ticket"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Linear is connected in the ClawLink dashboard
- Confirm the connected Linear account belongs to the right workspace/team
