## At a glance

- Good for triage, sprint support, backlog cleanup, and issue creation.
- Linear is especially useful when you want OpenClaw to turn raw notes into action items.
- If teams/projects do not appear correctly, the connected account likely lacks workspace access.

## Example prompts

- "Create a Linear issue from this bug report"
- "Summarize urgent issues in the current cycle"
- "Find all Linear issues assigned to me"
- "Turn this meeting note into a Linear ticket"

## If it does not work

- Start a fresh agent session after setup so the ClawLink tools load
- Make sure you approved the browser pairing flow
- Make sure Linear is connected in the ClawLink dashboard
- Confirm the connected Linear account belongs to the right workspace/team
