# Connect OpenClaw to LinkedIn

Use this if you want OpenClaw to help with LinkedIn posts, profile/company updates, and professional-content workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect LinkedIn">
    Go to the ClawLink dashboard and connect **LinkedIn**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use LinkedIn.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Useful for content drafting, post preparation, and supported LinkedIn publishing flows.
- LinkedIn integrations often depend on the account type and approved app permissions.
- If you need company-page actions, make sure the connected account has page access.

## Example prompts

- "Draft a LinkedIn post announcing our new feature"
- "Turn this changelog into a founder-style LinkedIn update"
- "Create a short LinkedIn post from this product note"
- "Help me draft a LinkedIn launch post for ClawLink"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure LinkedIn is connected in the ClawLink dashboard
- Check that the connected LinkedIn account has permission for the profile or company page you want
