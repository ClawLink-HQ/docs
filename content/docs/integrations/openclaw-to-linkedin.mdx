## At a glance

- Useful for content drafting, post preparation, and supported LinkedIn publishing flows.
- LinkedIn integrations often depend on the account type and approved app permissions.
- If you need company-page actions, make sure the connected account has page access.

## Example prompts

- "Draft a LinkedIn post announcing our new feature"
- "Turn this changelog into a founder-style LinkedIn update"
- "Create a short LinkedIn post from this product note"
- "Help me draft a LinkedIn launch post for ClawLink"

## If it does not work

- Start a fresh agent session after setup so the ClawLink tools load
- Make sure you approved the browser pairing flow
- Make sure LinkedIn is connected in the ClawLink dashboard
- Check that the connected LinkedIn account has permission for the profile or company page you want
