# Connect OpenClaw to Shopify

Use this if you want OpenClaw to help with Shopify orders, products, and store operations.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Shopify">
    Go to the ClawLink dashboard and connect **Shopify**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Shopify.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Good for order lookups, product operations, and store support workflows.
- Shopify can be high leverage for support, fulfillment, and reporting tasks.
- If data looks wrong, make sure the connected store is the one you meant to use.

## Example prompts

- "Look up the latest Shopify orders"

- "Find this customer in Shopify and show their order history"
- "Create an operations summary from recent Shopify activity"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Shopify is connected in the ClawLink dashboard
- Confirm the connected Shopify store and app permissions match what you need
