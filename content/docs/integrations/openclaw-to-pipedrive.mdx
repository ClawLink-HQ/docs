# Connect OpenClaw to Pipedrive

Use this if you want OpenClaw to help with Pipedrive deals, contacts, and sales workflows.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Pipedrive">
    Go to the ClawLink dashboard and connect **Pipedrive**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Pipedrive.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Good for deal updates, contact management, and simple pipeline workflows.
- Useful when your sales process still lives in a relatively lean CRM setup.
- If stages or people look wrong, the connected Pipedrive workspace is usually the issue.

## Example prompts

- "Create a new Pipedrive deal from this lead"
- "Summarize open deals in Pipedrive"
- "Find this contact in Pipedrive"
- "Update the stage for this opportunity in Pipedrive"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Pipedrive is connected in the ClawLink dashboard
- Confirm the connected Pipedrive account is the right workspace and has the expected permissions
