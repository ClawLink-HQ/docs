## At a glance

- Good for deal updates, contact management, and simple pipeline workflows.
- Useful when your sales process still lives in a relatively lean CRM setup.
- If stages or people look wrong, the connected Pipedrive workspace is usually the issue.

## Example prompts

- "Create a new Pipedrive deal from this lead"
- "Summarize open deals in Pipedrive"
- "Find this contact in Pipedrive"
- "Update the stage for this opportunity in Pipedrive"

## If it does not work

- Start a fresh agent session after setup so the ClawLink tools load
- Make sure you approved the browser pairing flow
- Make sure Pipedrive is connected in the ClawLink dashboard
- Confirm the connected Pipedrive account is the right workspace and has the expected permissions
