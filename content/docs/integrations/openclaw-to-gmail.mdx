# Connect OpenClaw to Gmail

![OpenClaw and Gmail connection concept](/images/articles/clawlink-gmail-hero.png)

Use this if you want OpenClaw to help with email, drafts, and inbox tasks.

### 2) Connect Gmail and read emails

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect Gmail">
    Go to the ClawLink dashboard and connect **Gmail**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use Gmail.
  </Step>
</Steps>

## Example prompts

- "Draft a reply to the latest email from Sarah"
- "Summarize my unread emails from today"
- "Find the thread about pricing"
- "Write a follow-up email from these notes"

## If it does not work

- Start a **new OpenClaw chat** after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure Gmail is connected in the ClawLink dashboard
