## At a glance

- Good for issue triage, repo lookups, PR support, and lightweight engineering ops.
- Works best when the connected GitHub account already has repo access in the org you care about.
- If actions look incomplete, permission scope on the token/account is usually the problem.

## Example prompts

- "Open a GitHub issue from this bug report"
- "Summarize the latest pull requests in this repo"
- "Find the open issues labeled urgent"
- "Create a release checklist issue in GitHub"

## If it does not work

- Start a fresh agent session after setup so the ClawLink tools load
- Make sure you approved the browser pairing flow
- Make sure GitHub is connected in the ClawLink dashboard
- Confirm the connected GitHub account or token has repo access to the target project
