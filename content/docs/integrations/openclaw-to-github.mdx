# Connect OpenClaw to GitHub

Use this if you want OpenClaw to help with repos, issues, pull requests, and engineering workflows in GitHub.

## Copy and paste this

```bash
openclaw plugins install clawhub:clawlink-plugin
```

## Simple setup

<Steps>
  <Step title="Install the plugin">
    Run the command above in OpenClaw.
  </Step>
  <Step title="Pair ClawLink">
    Ask OpenClaw to set up ClawLink or pair ClawLink.
  </Step>
  <Step title="Approve in your browser">
    Open the link OpenClaw gives you and approve the device.
  </Step>
  <Step title="Connect GitHub">
    Go to the ClawLink dashboard and connect **GitHub**.
  </Step>
  <Step title="Start using it">
    Go back to OpenClaw and ask it to use GitHub.
  </Step>
</Steps>

## ![Wrench icon](/images/icons/wrench.svg) At a glance

- Good for issue triage, repo lookups, PR support, and lightweight engineering ops.
- Works best when the connected GitHub account already has repo access in the org you care about.
- If actions look incomplete, permission scope on the token/account is usually the problem.

## Example prompts

- "Open a GitHub issue from this bug report"
- "Summarize the latest pull requests in this repo"
- "Find the open issues labeled urgent"
- "Create a release checklist issue in GitHub"

## If it does not work

- Start a new OpenClaw chat after installing the plugin
- Make sure you approved the browser pairing flow
- Make sure GitHub is connected in the ClawLink dashboard
- Confirm the connected GitHub account or token has repo access to the target project
