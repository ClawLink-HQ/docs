## Profile

- **Name**: edit it and click **Save changes**.
- **Email**: set by your sign-in provider. You cannot change it here.
- **Avatar**: click **Change avatar** to upload a picture.
- **Language**: the language of your dashboard.

## Developer

The Developer tab asks **Where does your agent run?** and gives you the setup for that answer:

| Answer | What you get |
|---|---|
| **On my computer** | `npx -y @useclawlink/cli login`. Run it where the agent runs. It signs you in. |
| **In ChatGPT or Claude** | A connector to paste into ChatGPT or Claude. Approve when it asks. |
| **Any MCP client** | The MCP endpoint `https://claw-link.dev/api/mcp` (Streamable HTTP). Your client signs in with OAuth, or sends an API key as a Bearer token. |

### API keys

Under **Manual key**, for agents that cannot run the login command, you can:

- Create a `cllk_live_...` key and give it a name.
- Copy the raw key once, right after you create it.
- See when each key was created and last used.
- Revoke a key you no longer trust.

<Warning>
  A raw key shows only once. If you lose it, revoke it and create a new one.
</Warning>

<Tip>
  Building on ClawLink's HTTP API with a key? See the [Developer API](/api/overview) for endpoints, the `confirm` field, file uploads and curl examples.
</Tip>

## Security

**Manage** opens your account screen for:

- Password and email changes
- Connected sign-in methods
- Any extra protection your sign-in method supports
