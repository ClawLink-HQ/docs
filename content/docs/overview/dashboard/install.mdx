The **Install** page is the fastest way to start. Pick your agent, and the page gives you the exact command or prompt for it, with a copy button. It changes together with the product, so it is always current.

<LogoRow apps="openclaw hermes claude cursor codex grokbot muse claude-ai chatgpt" labels />

## The three steps

<Steps>
  <Step title="Set up your agent">
    Pick your agent. The page shows what to run:

    - **OpenClaw** and **Hermes**: the plugin install and pairing steps. See [OpenClaw setup](/openclaw) and [Hermes setup](/hermes).
    - **Claude Code** and **Cursor**: two commands. The first signs you in, the second adds ClawLink to the agent.
    - **Codex**, **Grok Bot** and any other agent: one command, `npx -y @useclawlink/cli login`, run where the agent runs.
    - **Muse**: one prompt to paste into Muse. Muse sets up ClawLink and sends you one link to approve.
    - **ChatGPT** and **Claude.ai**: add ClawLink as a connector, then approve when it asks.
  </Step>
  <Step title="Connect an app">
    Click an app chip to start its hosted connect flow. Your agent can only use the apps you connect.
  </Step>
  <Step title="Try it out">
    Copy a prompt and send it to your agent.
  </Step>
</Steps>
