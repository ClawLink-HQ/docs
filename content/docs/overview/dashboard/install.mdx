The **Install** page is the fastest place to start if you want the product to hand you the right setup flow instead of piecing it together from older docs.

## What the Install page is for

- Getting the current OpenClaw setup instructions
- Copying the Hermes bootstrap prompt
- Jumping into pairing without hunting through the rest of the dashboard

## Which path to use

<CardGroup cols={2}>
  <Card title="OpenClaw" icon="terminal" href="/openclaw">
    Install the plugin, start browser pairing, approve the device, then connect apps.
  </Card>
  <Card title="Hermes" icon="sparkles" href="/hermes">
    Copy the Hermes install prompt from the dashboard, paste it into Hermes, and approve pairing.
  </Card>
</CardGroup>

## After install

No matter which client you use, the next step is the same:

1. Open **Dashboard > Connections**
2. Click **Add connection**
3. Finish the hosted connect flow for the apps you want
4. Return to your agent and ask it to use those apps

<Tip>
  Treat the dashboard install page as the canonical handoff for setup. It is closer to the product than one-off support articles, so it is the best place to start when a flow changes.
</Tip>
