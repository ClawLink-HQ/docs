<AccordionGroup>
  <Accordion title="What is ClawLink?">
    ClawLink connects your AI agent to the apps you use. Install it once, pair once, connect apps from the dashboard, and ClawLink handles the sign-in, credentials and retries for each app.
  </Accordion>

  <Accordion title="Do I need OpenClaw to use ClawLink?">
    No. ClawLink works with OpenClaw, Hermes, Claude Code, Cursor, Codex, Grok Bot, Muse, ChatGPT, Claude.ai and any MCP client. The setup changes a little per agent, but your account and connections are the same for all of them. See [Install ClawLink](/install).
  </Accordion>

  <Accordion title="How is ClawLink different from calling APIs directly?">
    If you wire providers directly, you own auth flows, token refresh, permission drift, retries, logging, and failure handling. ClawLink does that work, so your agent can just use the connected tools.
  </Accordion>

  <Accordion title="Are my provider credentials stored on my machine?">
    No. Provider credentials never touch your machine. For hosted OAuth connections, tokens are held by Composio, ClawLink's credential partner. ClawLink keeps only a reference to your connected account. API keys you enter manually are encrypted with AES-256-GCM at rest. Your local client stores only the ClawLink device credential created during pairing. See [Security](/security) for details.
  </Accordion>

  <Accordion title="Which integrations are supported?">
    1,000+ apps across communication, productivity, developer tools, CRM, payments, analytics, storage, marketing, AI and commerce, plus [public data apps](/integrations/public-data) that need no connection. See [Integrations](/integrations/overview). The dashboard catalog is always the current list.
  </Accordion>

  <Accordion title="How do I set it up in OpenClaw?">
    Install the plugin, start browser pairing, approve the device, then connect apps from **Dashboard > Connections**. See [OpenClaw setup](/openclaw) for the full walkthrough.
  </Accordion>

  <Accordion title="How do I set it up in Hermes?">
    Install the Hermes plugin, run `hermes clawlink begin`, approve the link in your browser, then connect apps from the dashboard. See [Hermes setup](/hermes).
  </Accordion>

  <Accordion title="How do I add an integration that isn't listed?">
    Click **Request an app** on the Connections page, or ask in the [Discord community](https://discord.gg/KjN3xcTvw4).
  </Accordion>

  <Accordion title="Do I need to write any code?">
    No. You connect apps in the dashboard and talk to your agent in plain language. If you want to call ClawLink from your own code, see the [Developer API](/api/overview).
  </Accordion>

  <Accordion title="What happens if an API call fails?">
    ClawLink retries short failures when it can. If a call still fails, it shows in **Dashboard > Logs** with the app, the action, the input and the error.
  </Accordion>

  <Accordion title="Can I use ClawLink on multiple installs?">
    Yes. Pair each install on its own, so each has its own device credential. All of them use the same connected apps. You can see and revoke them in **Dashboard > Devices**.
  </Accordion>

  <Accordion title="What are public data apps?">
    Read-only apps for public data: TikTok, Instagram, X, YouTube, LinkedIn, Reddit, SEO, AI search answers, crypto and stock prices. There is nothing to connect, and each call is paid from your data credit, not from your plan. See [Public data apps](/integrations/public-data).
  </Accordion>

  <Accordion title="Is there a free plan?">
    New accounts get a **7-day free trial** with the first app included and no card required. After that, continue on **Starter** (\$6/mo) or **Ultra Heavy** (\$30/mo, 100,000 tool calls a month). See the [Billing](/billing) page for details.
  </Accordion>

  <Accordion title="How do I contact support?">
    The fastest path is the **support chat in the dashboard**. Open it from the chat button, and a real person replies within a few minutes. For bugs or feature requests, you can also post in the [Discord community](https://discord.gg/KjN3xcTvw4). For security issues, email **security@claw-link.dev**.
  </Accordion>
</AccordionGroup>
