## Set up ClawLink for Hermes

<Steps>
  <Step title="Install the plugin">
    ```bash
    hermes plugins install ClawLink-HQ/hermes-plugin --enable
    ```
  </Step>

  <Step title="Start pairing">
    ```bash
    hermes clawlink begin
    ```

    This prints a browser approval link.
  </Step>

  <Step title="Approve in your browser">
    Open the link and approve the device.
  </Step>

  <Step title="Finish setup">
    ```bash
    hermes clawlink finish
    hermes clawlink test
    ```

    `test` confirms that ClawLink is ready.
  </Step>

  <Step title="Connect your first app">
    In **Dashboard > Connections**, click **Add connection** and complete the hosted flow for the app you want Hermes to use.
  </Step>

  <Step title="Ask Hermes to use the connected app">
    When the connection is ready, Hermes can call the app's tools directly from chat.
  </Step>
</Steps>

<Tip>
  You can also give the whole flow to Hermes as one prompt. **Dashboard > Install** has a version you can copy. Not using Hermes? See [Install ClawLink](/install) for the CLI and the OpenClaw plugin.
</Tip>

## Notes

- If you just installed the plugin and Hermes cannot see the ClawLink tools, restart the session and try again.
- Browser pairing is the recommended flow. You do not need to move provider credentials through chat.
- Your connected apps belong to your ClawLink account, so every agent you pair can use them.

<Note>
  The install prompt in **Dashboard > Install** is the source of truth for the exact Hermes steps, because it changes together with the product.
</Note>
