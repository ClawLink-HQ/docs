ClawLink works with OpenClaw through the ClawLink plugin. Install the plugin, pair the device in your browser, then connect apps from the ClawLink dashboard.

## Install the plugin

The recommended install uses ClawHub:

```bash
openclaw plugins install clawhub:clawlink-plugin
openclaw gateway restart
```

npm also works:

```bash
openclaw plugins install @useclawlink/openclaw-plugin
openclaw gateway restart
```

If the current chat started before you installed the plugin and the ClawLink tools do not show, start a new chat. OpenClaw then reloads the tool catalog.

## Pair this device

<Steps>
  <Step title="Start browser pairing">
    In OpenClaw, ask the assistant to set up ClawLink or start pairing. The plugin calls `clawlink_begin_pairing` and returns a browser URL.
  </Step>

  <Step title="Approve this device in your browser">
    Open the pairing URL, sign in to ClawLink if necessary, and click **Approve this device**.
  </Step>

  <Step title="Let OpenClaw finish the pairing check">
    Go back to OpenClaw. The plugin saves the device credential and confirms that the device is paired.
  </Step>

  <Step title="Connect apps from the dashboard">
    Open **Dashboard > Connections**, add the apps you want, and use them from OpenClaw.
  </Step>
</Steps>

## What pairing stores locally

Pairing stores a ClawLink device credential in `~/.openclaw/openclaw.json`. You never paste that key into chat: OpenClaw saves it for the plugin when you approve the device. Your provider tokens (Google, Slack, Stripe and others) stay with ClawLink and never reach this file.

## Tools the plugin adds

| Job | Tools |
|---|---|
| Pair the device | `clawlink_begin_pairing`, `clawlink_get_pairing_status` |
| Connect apps | `clawlink_list_integrations`, `clawlink_start_connection`, `clawlink_get_connection_status` |
| Find the right action | `clawlink_search_tools`, `clawlink_list_tools`, `clawlink_describe_tool` |
| Run it | `clawlink_preview_tool`, `clawlink_call_tool`, `clawlink_get_result` |

## Manual fallback

Use an API key only when your OpenClaw client has a plugin settings screen and browser pairing is not available:

1. Create a key in **Settings > Developer**.
2. Copy the raw `cllk_live_...` value when it shows. It shows only once.
3. Paste it into the plugin settings field for `clawlink-plugin`.

Most users can skip this and use browser pairing.
