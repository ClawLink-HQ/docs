Every setup path ends in the same place: a paired device, and a dashboard where you connect apps. Pick the path that matches your agent.

<Note>
  Before you start, create an account at [claw-link.dev](https://claw-link.dev). New accounts get a 7-day free trial. The first app is included, and you do not need a card.
</Note>

## Which path for your agent

| Agent | Setup |
| --- | --- |
| <AppLogo app="openclaw" size={22} className="mr-2 align-middle" /> **OpenClaw** | The OpenClaw plugin from ClawHub. See [OpenClaw setup](/openclaw). |
| <AppLogo app="hermes" size={22} className="mr-2 align-middle" /> **Hermes** | The Hermes plugin. See [Hermes setup](/hermes). |
| <AppLogo app="claude" size={22} className="mr-2 align-middle" /> **Claude Code** | `npx -y @useclawlink/cli login`, then `npx -y @useclawlink/cli install claude-code` |
| <AppLogo app="cursor" size={22} className="mr-2 align-middle" /> **Cursor** | `npx -y @useclawlink/cli login`, then `npx -y @useclawlink/cli install cursor` |
| <AppLogo app="codex" size={22} className="mr-2 align-middle" /> **Codex**, <AppLogo app="grokbot" size={22} className="mx-2 align-middle" /> **Grok Bot**, any other agent | `npx -y @useclawlink/cli login`, run where the agent runs |
| <AppLogo app="muse" size={22} className="mr-2 align-middle" /> **Muse** | Paste the Muse prompt from **Dashboard > Install** |
| <AppLogo app="chatgpt" size={22} className="mr-2 align-middle" /> **ChatGPT**, <AppLogo app="claude-ai" size={22} className="mx-2 align-middle" /> **Claude.ai** | Add ClawLink as a connector. **Dashboard > Install** shows the steps |

**Dashboard > Install** always shows the current command for each agent, with a copy button.

## After setup

Whichever path you used, the rest is the same:

<Steps>
  <Step title="Connect an app">
    In the dashboard, open **Connections** > **Add connection**, pick the app, and complete the hosted flow. See [Connecting accounts](/dashboard/integrations).
  </Step>
  <Step title="Check it worked">
    Ask your agent to do something small with the app: read the latest email, or list a few issues. [Logs](/dashboard/request-logs) show every call.
  </Step>
</Steps>
