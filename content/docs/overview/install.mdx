ClawLink supports three setup paths. They all end in the same place — a paired
device and a dashboard where you connect apps — so pick whichever matches how
you work.

| Path | Use it when |
| --- | --- |
| **Agents** (`@useclawlink/cli`) | You use any agent, or more than one. This is the agent-agnostic route and the one most people want. |
| **Hermes** | You run Hermes and want the plugin wired into it directly. |
| **OpenClaw** | You run OpenClaw and want the ClawHub plugin. |

<Note>
  Before you start, create an account at [claw-link.dev](https://claw-link.dev). New
  accounts get a 7-day free trial and the first app is included, no card required.
</Note>

## After setup

Whichever path you used, the rest is the same:

<Steps>
  <Step title="Connect an app">
    In the dashboard, open **Connections** → **Add connection**, pick the app, and
    complete the hosted flow. See [Connecting accounts](/dashboard/integrations).
  </Step>
  <Step title="Check it worked">
    Ask your agent to do something small with the app — read the latest email, list
    a few issues. [Request logs](/dashboard/request-logs) show every call.
  </Step>
</Steps>
